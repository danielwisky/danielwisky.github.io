{%- comment -%} Tells whether a post is a video lesson. Prints "1" when it is and nothing when it isn't, so the usage is to capture the output and test against empty string. The source is _data/videos.yml, generated by scripts/build-video-thumbs.mjs from the embed in the post body, so a post with a video doesn't miss the badge because someone forgot the tag. The Videoaula tag acts as a safety net. Note: no Liquid tags inside this comment — Liquid still parses tags inside comment, and an if without endif here breaks the build. {%- endcomment -%} {%- assign p = include.post -%} {%- if site.data.videos[p.slug] -%}1 {%- elsif p.tags contains 'Videoaula' -%}1 {%- endif -%}
